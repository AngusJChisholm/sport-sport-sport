# Sport Sport Sport - deal sources

The daily scan works through this list every weekday. Search it with `site:` queries for the last 24-48 hours
(e.g. `site:sportspro.com partnership`), plus plain-language searches like "named official partner", "signs
sponsorship", "naming rights", "jersey patch", "front-of-shirt" and "extends partnership".

## Accuracy rules

1. **Confirmed only.** A deal counts when the brand, the rights holder, or a reputable outlet reports it as
   signed. Rumours, "in talks" and "set to" stories are skipped.
2. **Official first.** Where possible, confirm on the rights holder's or brand's own newsroom (Tier 1).
3. **Two sources for anything big.** If a figure, length or "record/first" claim is used, it must appear in an
   official release or in two independent outlets. If not, leave the figure out.
4. **Date = announcement date**, not the date a story was republished.
5. **Brand first, then the property** in every deal name.

## Using this list
- Run at least one search per Tier 1 and Tier 2 group each morning.
- ANZ deals: always check the AFL, NRL, Cricket Australia, Football Australia and Tennis Australia newsrooms,
  plus B&T, mi-3 and Mumbrella.
- If a deal appears only in Tier 3 or 4, look for a Tier 1 or Tier 2 confirmation before using it.
